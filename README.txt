==============================
 APEX GIF MAKER - 사용 안내
==============================

동영상에서 원하는 구간만 골라, Flydigi APEX 컨트롤러 화면에 넣을 GIF를 쉽게 만드는 프로그램입니다.
APEX 4·5·6은 화면 규격이 같아서(기본 160×80) 어느 모델에서나 그대로 쓸 수 있습니다.


■ 처음 실행할 때

1. 압축을 푼 폴더에서 ApexGIFMaker.exe를 실행합니다. 따로 설치할 필요가 없습니다.
2. 처음 실행하면 동영상 변환 도구(ffmpeg)를 자동으로 내려받습니다.
   인터넷에 연결되어 있어야 하고, 1~2분 정도 걸릴 수 있습니다.
3. Windows가 "PC 보호" 창을 띄우면 [추가 정보] → [실행]을 누르세요.
   개인이 만든 프로그램이라 처음 보는 파일로 여겨서 나오는 안내입니다.


■ 사용 방법

1. [비디오 열기]를 누르거나, 동영상 파일을 창에 끌어다 놓습니다.
2. 가운데 타임라인에서 GIF로 만들 구간을 고릅니다.
   - 구간 양쪽 손잡이를 끌면 시작이나 끝만 바뀝니다.
   - 구간 가운데를 끌면 길이는 그대로 두고 위치만 옮겨집니다.
   - 빈 곳을 누르면 구간이 그 자리로 옮겨 갑니다.
   - 마우스 휠로 타임라인을 크게 늘리면 0.1초 단위로 고를 수 있습니다.
     (Shift+휠: 옆으로 이동, 구간을 두 번 누르기: 구간에 맞춰 크게 보기, 0 키: 전체 보기)
   - 시간 칸에 직접 적거나 ◀ ▶ 단추로 0.1초씩(Shift: 1초씩) 조정할 수도 있습니다.
3. 필요하면 GIF 옵션(크기, FPS, 스케일, 디더링, 프레임)을 바꿉니다.
   처음이라면 기본값(160×80, 12 FPS, 꽉 채우기) 그대로 두어도 됩니다.
4. [GIF 생성]을 누르면 GIF를 만들고, 결과를 바로 재생해 보여 줍니다.
5. Flydigi 공간정거장(Space Station) 앱의 화면 설정에서 만든 GIF를 컨트롤러에 올립니다.
   (앱 버전에 따라 메뉴 이름이 조금 다를 수 있습니다)

구간은 1초부터 30초까지 고를 수 있고, 15초 이하를 권장합니다.


■ 폴더 안내

  ApexGIFMaker.exe    프로그램
  bin\                프로그램이 쓰는 파일과 동영상 변환 도구(ffmpeg) (지우거나 옮기지 마세요)
  settings.json       설정 파일 (지우면 모든 설정이 처음 상태로 돌아갑니다)


■ 업데이트

새 버전이 나오면 프로그램이 알려 줍니다. [지금 업데이트]를 누르면 알아서 바꿔 줍니다.
내려받은 파일이 원본과 똑같은지(SHA-256 확인값) 확인한 뒤에만 설치하고, 설정과 ffmpeg는 그대로 남습니다.

동영상 변환 도구(ffmpeg)는 프로그램을 켤 때 새 버전이 있는지 확인해서 자동으로 최신으로 맞춥니다.
오른쪽 위 ⚙ 메뉴의 [도구 업데이트 (ffmpeg)]로 바로 받을 수도 있고, [도구 자동 업데이트]를 끄면 자동 확인을 멈춥니다.


■ 문제가 생기면

- ffmpeg를 내려받지 못했다면, https://www.gyan.dev/ffmpeg/builds/ 에서
  ffmpeg-release-essentials.zip을 받아 bin 폴더의 ffmpeg.exe, ffprobe.exe를
  이 프로그램의 bin 폴더에 직접 넣어 주세요.
- 그 밖의 문제는 창 아래 [로그]를 펼쳐 내용을 복사한 뒤 아래 주소로 알려 주세요.
  https://github.com/deuxdoom/APEXGIFMAKER/issues

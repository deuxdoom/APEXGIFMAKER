GOOD TO KNOW
시작하기 전에.
알아두면 더 간단해집니다.

      
컨트롤러로 바로 전송해 주나요?+
이 앱은 컨트롤러 스크린에 사용할 GIF 파일을 만드는 도구입니다. GIF 등록과 컨트롤러 전송은 별도의 Flydigi Space Station에서 진행합니다.

      
어떤 APEX 모델에 사용할 수 있나요?+
APEX 4·5·6처럼 같은 스크린 규격(기본 160×80)을 쓰는 모델이라면 사용할 수 있습니다. 크기는 8~4096 사이에서 바꿀 수도 있습니다. 등록 가능한 파일 조건은 모델·펌웨어와 Space Station에서 확인해 주세요.

      
따로 설치할 프로그램이 있나요?+
ZIP 파일의 압축을 모두 푼 뒤 ApexGIFMaker.exe를 실행하면 됩니다. 실행 파일 옆의 bin 폴더도 함께 두어야 합니다. 영상 변환 도구인 FFmpeg는 처음 실행할 때 확인값(SHA-256)을 검사한 뒤 자동으로 받으므로 이때 인터넷 연결이 필요합니다. GIF를 컨트롤러에 적용하려면 Flydigi Space Station이 필요합니다.

      
Windows에 ‘PC 보호’ 안내가 나와요.+
Windows가 아직 신뢰 정보가 충분하지 않은 앱에 표시할 수 있는 안내입니다. 이 저장소의 릴리스에서 직접 받은 파일인지 확인하고, 실행하기로 했다면 ‘추가 정보 → 실행’을 선택하세요.

      
영상이 서버에 업로드되나요?+
영상 변환은 PC 안에서 이루어지며 영상 파일을 서버에 업로드하지 않습니다. FFmpeg 다운로드와 새 버전 확인에만 인터넷 연결을 사용합니다.

      
업데이트는 어떻게 하나요?+
3.0.0부터는 새 버전이 나오면 앱이 알려 주고, ‘지금 업데이트’를 누르면 알아서 바꿔 줍니다. 2.x에는 이 기능이 없으므로 3.0.0 ZIP을 직접 받아 새 폴더에 풀어 주세요. 이전 폴더의 settings.json을 새 폴더로 복사하면 저장 폴더와 GIF 옵션을 이어서 쓸 수 있습니다.

      
FFmpeg를 받지 못했다고 나와요.+
인터넷 연결을 확인한 뒤 앱을 다시 실행해 보세요. 직접 준비하려면 FFmpeg Windows 빌드 배포처에서 ffmpeg-release-essentials.zip을 받고, 압축 안의 bin 폴더에서 ffmpeg.exe와 ffprobe.exe 두 파일만 ApexGIFMaker.exe 옆의 bin 폴더에 넣어 주세요.

      
설정은 어디에 저장되나요?+
프로그램 폴더의 settings.json에 저장됩니다. 그 폴더에 쓸 수 없다면(예: Program Files) %LOCALAPPDATA%\ApexGIFMaker에 저장합니다. 설정을 처음으로 되돌리려면 앱을 끈 뒤 이 파일을 지우세요.

      
무료인가요? Flydigi 공식 앱인가요?+
무료 MIT 오픈소스 프로젝트입니다. Flydigi의 공식 제품이 아닌 커뮤니티 제작 도구이며, 소스 코드와 변경 사항은 GitHub에서 확인할 수 있습니다.
